HTMLやZIPをiPhoneの「ファイル」アプリで開くだけではインストールできません。公開用ファイルを置くHTTPSのURLが必要です。

1. 無料のGitHub Pagesで公開

  1. PCでGitHubにサインインし、新しいリポジトリを作成。名前は rail-english など、公開範囲は Public にします。
  2. Add file → Upload files から、ZIPを展開した中の public の中身をアップロードします。index.html がリポジトリの最上位に来るようにしてください。icons フォルダーも必要です。
  3. Settings → Pages で、Sourceを Deploy from a branch、Branchを main、フォルダーを /(root) にして保存します。
  4. 公開処理が完了するとPages画面にHTTPSのURLが出ます。リポジトリ自体のURLではなく、その公開URLを使います。

独自ドメイン・Appleの有料開発者登録は不要です。無料の公開リポジトリでは、コードと問題集も公開になります。学習記録のバックアップはアップロードしないでください。

GitHub公式：サイトの作成 / 公開元の設定

2. iPhoneのホーム画面に追加

  1. 家のWi-Fiなどで、公開したURLを Safari で開きます。
  2. 共有メニューから ホーム画面に追加。表示される場合は Webアプリとして開く をオンにします。
  3. 追加したアイコンからアプリを開き直し、右上の オフライン準備完了 を確認します。
  4. 機内モードにしてWi-Fiもオフにし、アプリを終了して再起動。問題を解き、閉じて開いて記録が残るかを確認します。

Safariで準備ができても、ホーム画面のアプリ側で必ず再確認してください。

Apple公式：Webサイトをアプリにする

3. 毎日の使い方

ホーム → 今日の5問 → 4択で回答 → 正解文・和訳・解説 → 自信を記録の順です。1回10問や、コースの切り替えもホーム画面から行えます。

正解しても「迷った・勘だった」を押すと復習リストに残ります。間違いは自動で記録。中断した問題は、ホームの「続きから再開する」で戻れます。

コースごとに穴埋め30問＋読解10問。難易度は学習用の目安です。リスニング・長文の本格演習・模試は未収録で、本試験の予測スコアは表示しません。

保存と動作確認について

問題・解説・学習履歴は端末内で処理します。学習中の有料AIへの接続はありません。保存データはサイトデータの消去や容量不足などで失われることがあるため、設定 → 学習記録を書き出すで定期的にバックアップしてください。

画面操作の自動テストと、オフライン保存処理の模擬テストは実施済みです。iPhone実機・Safari・実際の機内モードでの起動は未確認なので、公開後に上の手順で確認してください。
