# Rail English 1.3.0

スマートフォンで単語・熟語を学ぶ、静的なオフライン対応PWAです。公開先は https://anthra2525.github.io/rail-english/ です。ビルドやアカウントは不要です。

## 日次目標と自由練習

単語320項目＋熟語・定型表現160項目を収録。意味の4択 → 例文・和訳・コロケーション → 自信の確認、の順に学びます。

- **日次目標**：新規5項目が初期値。設定で3 / 5 / 10 / 15項目に変更でき、期限の来た復習は全件追加します。初期値では両方の未学習項目がある間、単語3・熟語2を選びます。
- **自由練習**：ホームと完了画面から、10 / 20 / 30 / 50問（初期値20問）を選び、1日何セットでも練習できます。種類は「単語＋熟語」「単語」「熟語・表現」「間違い・迷い」。候補が少なければその数で開始します。
- セット完了画面の「何度でも、自由練習」で出題数・種類を選び、次のセットを開始できます。日次目標の完了後も利用できます。
- 自由練習は、その日の出題回数が少ない項目を優先します。開始済みの日次目標も出題済みとして扱い、補完する問題を選びます。同じ優先度内では期限到来・未学習を優先し、同条件の候補をランダムに並べます。1セット内で同じ項目は重複しません。
- 途中のセットは選択肢・回答・確定済み結果を保存し、「自由練習を再開」から続けられます。出題数・種類の変更はセット完了後に行います。復習一覧の1項目見直しから入っても、未完了セットがあればその続きに戻ります。

## 記録と復習の扱い

| 操作・記録 | 日次目標 | 自由練習 |
| --- | --- | --- |
| 問題を選ぶ時点 | 最初の開始時にその日の計画を固定 | セット開始時に固定、完了後は次セットを作成 |
| 回答だけ | 選択を保存、未確定 | 選択を保存、未確定 |
| 自信の確認 | 日次の実施数＋回答履歴＋復習予定 | 回答履歴＋復習予定。日次の実施数は増やさない |
| 完了 | 固定された全項目の確認で日次完了 | そのセットの結果表示。日次の計画・完了記録は変更しない |
| 日本時間の日付跨ぎ | 前日の未確定回答は前日・当日どちらの完了にも加算せず、当日の課題を開始 | 途中セットを継続。履歴の日付は確認した当日 |

自由練習で初めて学んだ項目も学習済みになり、その後に作成する日次目標の新規候補から外れます。すでに開始した日次目標は変更しません。確定した回答はセットごとの一意IDで履歴に追記するため、次のセットで以前の正誤を上書きしません。

復習予定は日次目標と自由練習で共通です。期限が来た日の自信のある正解に限り、1日に一度だけ1 → 3 → 7 → 14 → 30日の間隔へ進みます。期限前の正解は元の期限を延ばしません。間違い・迷いは翌日までに再確認し、同日のやり直しだけでは復習対象から外しません。実施済みと習得状況は別で、30日間隔への到達は永久的な習得を保証しません。

端末の時計が回答時刻より前へ戻った場合は、回答を未確定のまま保持し、日時設定の確認を案内します。時刻を戻した後、同じ回答を確定できます。連打や古い画面のボタンでは二重に記録しません。

従来のTOEIC問題300問、追加問題、学習履歴、中断セッションは「TOEIC問題モード」から利用できます。旧モードの復習アルゴリズムは今回の変更対象外です。

## データと互換性

- 保存キーは **rail-english-v1**、schemaVersionは1のまま。480項目の教材本文・ID、TOEIC300問の本文・IDを維持します。
- 既存の attempts / progress / extraQuestions / settings / session と未知フィールドを保持し、語彙は独立した vocabulary 内に保存します。
- vocabulary.days：日次計画・回答・完了時刻。vocabulary.practice：現在の自由練習セット。vocabulary.attempts：確定した全回答の追記履歴。vocabulary.progress：語彙共通の復習状況。
- vocabulary.settings.practiceSize / practiceKind は選択した自由練習の設定です。旧保存データにない場合は20問・単語＋熟語として扱い、破壊的な移行は行いません。
- cleanStateは有効な未知フィールドを維持してバックアップを読み込みます。非対応スキーマ・不正構造は元のlocalStorageを上書きせず読み込みを止め、設定から元データを書き出せます。
- **1.3.0のバックアップは1.3.0以降で復元してください。** 旧版には日付を跨ぐ自由練習の再開機能がありません。1.1.0は語彙フィールド自体を保持しません。
- 公開origin/pathとmanifestの id / start_url / scope は変更しません。別のURL・端末・ブラウザーとは保存領域が異なります。

## 起動

```powershell
node .\dev-server.cjs
```

http://127.0.0.1:4173/rail-english/ を開きます。Service Workerを利用するためfile URLではなくlocalhostを使います。初回に「オフライン準備完了」を確認してから圏外で再読込してください。

Dドライブの既存ツールを使う場合：

```powershell
Set-Location 'D:\Codex\rail-english-practice-2026-10-26'
& 'D:\Codex\rail-english-vocabulary-2026-10-06\tools\node.exe' .\dev-server.cjs
```

## 検証

依存のないNodeテスト：

```powershell
node --test .\tests\core.cjs .\tests\practice.cjs
```

ブラウザー試験はPlaywrightとChrome for Testingを使います。公開資材には含めません。RAIL_TEST_TOOLSはplaywright/packageとbrowser/chrome-win64/chrome.exeがあるフォルダー、RAIL_TEST_OUTPUTは試験結果・一時プロファイルの保存先です。RAIL_TEST_BASEは更新前v1.2.1（1f4911ff65b40d32786c2d2a2316d5d06027fa7f）の展開先を指定します。

```powershell
$env:RAIL_TEST_TOOLS='D:\Codex\rail-english-vocabulary-2026-10-06\tools'
$env:RAIL_TEST_OUTPUT='D:\Codex\rail-english-practice-2026-10-26-review'
$env:RAIL_TEST_BASE='D:\Codex\rail-english-practice-2026-10-26-review\baseline'
# 別プロセスでdev-server.cjsを起動した上で実行：
& "$env:RAIL_TEST_TOOLS\node.exe" .\tests\browser.cjs
& "$env:RAIL_TEST_TOOLS\node.exe" .\tests\practice-browser.cjs
& "$env:RAIL_TEST_TOOLS\node.exe" .\tests\upgrade.cjs
```

browser.cjs / practice-browser.cjsは4173番の開発サーバーを使用し、upgrade.cjsは4174番に一時サーバーを起動します。試験結果JSONと画面PNGを出力先に保存します。検証範囲は、日次との分離、繰り返し、全480項目の利用、途中再開、日付跨ぎ・時計逆行、少数・空候補、誤答復習、連打、複数タブ、旧データ・バックアップ、オフライン、SW更新成功・失敗です。

実機iPhone / Safari / ホーム画面追加の検証は未実施です。

## ファイルと公開手順

公開資材はindex.html、vocabulary-data.js、vocabulary-core.js、vocabulary-ui.js、sw.js、manifest.webmanifest、icons/です。開発サーバーとtests/は検証用です。HTMLのAPP_VERSIONとSWのVERSIONはともに1.3.0です。

1. 現行公開版の「設定」→「学習記録を書き出す」でバックアップします。
2. 最新mainとローカル変更を確認し、他の作業を上書きせずに差分を適用します。今回の基点はv1.2.1の1f4911ff65b40d32786c2d2a2316d5d06027fa7fです。
3. 全テストと画面・差分レビューを行います。GitHub Pagesの既存公開元を維持します。
4. ユーザーの公開承認後にコミット・通常push・必要なレビュー／マージを行います。force pushは使いません。
5. GitHub Actionsのpages build and deploymentで、対象コミットの成功を確認します。公開HTML・SW・主要アセットが同じリリースか照合します。
6. iPhoneでは通信できる状態で普段のRail Englishを開き、必要なら一度閉じて開き直します。「設定」に更新ボタンが出たら回答の自信確認を終えてから更新します。TOEICの中断セッションがある場合は先に完了してください。
7. 設定のバージョン1.3.0と「オフライン準備完了」を確認します。ホームの「何度でも、自由練習」で出題数を選びます。更新後も同じURL・ブラウザーを使い、履歴確認のためにサイトデータを削除しないでください。
8. 同じ端末で履歴、自由練習、機内モードでの再起動を確認します。SWは全資材の保存に成功してから更新候補になり、資材取得失敗時は既存の版を維持します。
